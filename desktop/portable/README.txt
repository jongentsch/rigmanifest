RigManifest Portable
====================

Run RigManifest.exe directly. No installation is required.

Keep this entire folder together when moving or backing up RigManifest. The data
folder contains the workspace database, including user-defined frequencies,
frequency sets, radios, profiles, and preferences.

Removing rigmanifest-portable.marker changes RigManifest back to normal installed
behavior and makes it use the operating system's application-data directory.
